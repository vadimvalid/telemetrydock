# 2-minute demo script

1. **Overview (20 sec):** Show live metrics, device status counts, and a telemetry chart.
2. **Sensor (20 sec):** Open a temperature sensor and enable the overheating scenario.
3. **Automation (30 sec):** Create or enable a rule: temperature > 28°C → turn fan ON.
4. **Live response (20 sec):** Show the fan status changing and the latest command.
5. **Events (20 sec):** Show the trigger, action, and timestamps in the event log.
6. **Engineering (10 sec):** Briefly explain typed domain models, test coverage, and how MQTT could be added later.

Do not claim real hardware support unless it has actually been implemented and tested.
